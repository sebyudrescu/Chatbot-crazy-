🛠️ Istruzioni per l'Implementazione

Per integrare questo widget nel tuo sito:

  1. Vai alla sezione "Widget" del tuo chatbot nel dashboard
  2. Abilita il widget e configura le impostazioni
  3. Copia il codice di integrazione fornito
  4. Incolla il codice prima del tag </body> nel tuo sito

Codice di esempio:

<script> window.ChatbotConfig = { botId: 'your-bot-id', apiUrl: 'https://your-domain.com', theme: 'light', position: 'bottom-right', primaryColor: '#007bff' }; </script> <script src="https://your-domain.com/api/embed/widget.js?botId=your-bot-id"></script>
